# Saryarka Kitchen — Endterm Project

## Project topic
A responsive restaurant website for Saryarka Kitchen, a student project presenting Kazakh and Central Asian food in Astana.

## Group members
- Matiullah Zaman
- Zainap Noori

## Short description
Saryarka Kitchen is a multi-page restaurant website based on the original Midterm Project. It keeps the original design, pages, navigation, restaurant information, menu, gallery, and reservation details. The Endterm version adds JavaScript and jQuery interactions to make the website more functional.

## Features implemented
- Five connected pages: Home, About, Menu, Gallery, and Reservations.
- Responsive layout using Bootstrap 5.3.3 and the existing custom CSS.
- Guest registration form with required-field checks, email RegEx validation, password strength feedback (weak, medium, strong), password confirmation, and real-time messages.
- Menu search that filters results while the user types; search is case-insensitive.
- Category filter buttons for All, Meat, Vegetarian, Dessert, and Drinks. Search and category filters work together.
- Dynamic menu table with Create, Read, Update, and Delete operations. Delete asks for confirmation.
- Gallery lightbox with enlarged images, previous/next navigation, keyboard arrow navigation, and jQuery fade transitions.

## Technologies used
- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript
- jQuery 3.7.1
- Bootstrap Modal component
